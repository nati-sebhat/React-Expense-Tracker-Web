# 💸 Expensiya

A simple expense tracker built with React and Tailwind CSS.

## Features

- Add, edit, and delete income/expense transactions
- Filter by category and search by description
- Automatic totals for income, expenses, and balance
- Data persisted with Local Storage
- Dark mode toggle
- Responsive layout

## Tech Stack

- React
- Tailwind CSS
- JavaScript

## Getting Started

```bash
npm install
npm start
```
